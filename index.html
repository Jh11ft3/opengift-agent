⚡ curl 一键下载安装

把下面的 你的域名 替换成部署好的网址（例如 https://你的用户名.github.io/opengift）
方式 A：直接下载脚本（最简单，免安装） 
curl -fsSL https://jh11ft3.github.io/opengift-agent/opengift.py -o opengift.py
python3 opengift.py --config
python3 opengift.py
方式 B：curl 下载 + pip 安装成全局命令（推荐） 
curl -fsSL https://jh11ft3.github.io/opengift-agent/opengift-0.2.0-py3-none-any.whl -o opengift-0.2.0-py3-none-any.whl
pip install opengift-0.2.0-py3-none-any.whl
opengift
方式 C：一键脚本（自动下载，提示下一步） 
curl -fsSL https://jh11ft3.github.io/opengift-agent/install.sh -o install.sh && sh install.sh

🚀 站长：如何部署这个网页（让别人也能 curl 下载）

把这个文件夹里 4 个文件全部上传到任意静态托管即可：
index.html（本页）· opengift.py（源码）· opengift-0.2.0-py3-none-any.whl（安装包）· install.sh（一键脚本）

GitHub Pages：新建仓库 → 上传这 4 个文件到根目录 → Settings → Pages → 选 main 分支根目录 → 发布。
发布后把页面里所有 https://你的域名/ 换成你的真实网址（如 https://用户名.github.io/仓库名/）。
Vercel / Netlify：把文件夹直接拖进去，一键部署，自动生成公开链接。
